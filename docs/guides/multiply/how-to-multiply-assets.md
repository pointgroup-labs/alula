# How to Multiply Assets

{% stepper %}
{% step %}
Go to **Multiply**.
{% endstep %}

{% step %}
Press **Multiply** for the vault you want.
{% endstep %}

{% step %}
Enter an amount (or press **MAX**).
{% endstep %}

{% step %}
Choose your leverage using the **Multiplier** slider. As you move the slider, Alula updates the estimates for the position.
{% endstep %}

{% step %}
Review the details:

* **Liquidity Available:** How much the pool can currently lend for the loop. If liquidity is low, you may not be able to open the position at your chosen multiplier.
* **Max Multiplied Amount:** The maximum position size you can reach based on your deposit, the selected multiplier, and available liquidity.
* **Operation Fee**: A protocol fee shown in the asset units (for example, USDC) when applicable.
* **Transaction Fee**: The network fee required to submit the transaction.
{% endstep %}

{% step %}
Press **Multiply** to open the position and confirm the transaction in your wallet.
{% endstep %}
{% endstepper %}
