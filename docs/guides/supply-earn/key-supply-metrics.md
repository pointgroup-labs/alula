# Key Supply Metrics

In the **Markets** table, you’ll see these fields for each asset:

* **Supply**: Total amount currently supplied to that pool.
* **Supply APY**: The yield suppliers earn from borrower interest, net of protocol fees. It can change based on utilization and pool configuration. A portion of borrower interest may be diverted to protocol beneficiaries (such as the insurance fund or treasury). The APY you see is already net of these fees.
* **Utilization**: How much of the pool is currently borrowed. Higher utilization usually means higher rates.
* **Open LTV**: The max borrowing limit your collateral can support if you choose to use supplied assets as collateral. (If you’re only earning, this is mostly informational.)
