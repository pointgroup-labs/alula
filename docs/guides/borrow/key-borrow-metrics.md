# Key Borrow Metrics

In the **Markets** table, you’ll see these fields for each asset:

* **Borrow**: How much of the asset is currently borrowed from the pool.
* **Borrow APY**: The current annualized interest rate borrowers pay. It usually changes with market conditions, especially utilization. If utilization rises, borrowing typically becomes more expensive.
* **Utilization**: How much of the pool is currently borrowed. Higher utilization usually means higher rates.
* **Open LTV:** Borrowing limit that affects how much you can borrow based on your collateral.
* **Close LTV:** A risk parameter used in liquidation checks.
