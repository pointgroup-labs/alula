# How to Repay Borrows

{% stepper %}
{% step %}
Go to **My Account**.
{% endstep %}

{% step %}
Under **Your Borrows**, press **Repay** for the asset you want.
{% endstep %}

{% step %}
Enter an amount (or select **MAX**).
{% endstep %}

{% step %}
Review **Borrow Balance after Repayment**. This shows what your remaining debt would be if you proceed with the repayment amount you entered.
{% endstep %}

{% step %}
Press **Repay** and confirm the transaction in your wallet.
{% endstep %}
{% endstepper %}
