# Key Multiply Metrics

In the **Multiply** table, you’ll see these fields for each vault:

* **Vault:** Multiply strategies you can use (for example, an XLM/USDC vault).
* **APY:** The current estimated annualized yield for the vault at the current market conditions. It can change as borrowing costs and vault conditions change.
* **Multiplier:** How much maximum exposure the vault enables. Higher multipliers usually mean higher potential returns and higher risk.
* **Market:** Which market the vault uses (for example, Main).
* **Borrow:** The total amount of assets borrowed from the vault.
* **Supply:** The total amount of collateral deposited to the vault.
* **Borrow Token:** The asset borrowed from the vault.
